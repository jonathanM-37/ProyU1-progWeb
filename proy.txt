Dashboard del administrador
Cuando el usuario sea administrador, el sistema deberá mostrar un dashboard que incluya al menos:

Una gráfica con información del sistema

La gráfica puede mostrar por ejemplo:

Ventas

Productos

Distribución de datos

Puede utilizarse alguna biblioteca como:

Chart.js

Google Charts

----
Vista del cliente
Cuando el usuario sea cliente, el sistema deberá mostrar un catálogo de productos.

Cada producto debe mostrar al menos:

Nombre

Precio

Existencias

Imagen del producto

El cliente podrá seleccionar productos para simular una compra.
